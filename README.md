#  TV App

A SwiftUI-based **Apple TV-inspired streaming app replica** built for iOS.

This project recreates the experience of a modern streaming platform with a cinematic interface for discovering movies and TV shows, viewing detailed content information, searching for titles, and watching trailers.

> **Note:** This is an independent project inspired by the Apple TV interface. It is not affiliated with, sponsored by, or endorsed by Apple.

---

## 📱 About

The **TV App** is an independent Apple TV-inspired streaming application built using SwiftUI.

The app focuses on creating a clean, immersive, and cinematic streaming experience with large artwork, smooth navigation, detailed movie and TV show pages, search, trailers, and content discovery.

The project was built from scratch as an iOS development and UI/UX project.

---

## ✨ Features

### 🏠 Home

- Featured movie and TV show content
- Cinematic hero section
- Continue Watching section
- Content discovery rows
- Quick Play and Add actions
- Apple TV-inspired bottom navigation

### 🎬 Movie Details

- Movie title and artwork
- Genres and release information
- Ratings
- Description
- Play action
- Add to library action
- Available trailers

### 📺 TV Show Details

- Show information
- Seasons
- Episodes
- Episode thumbnails
- Season selection
- Play First Episode
- Trailer content

### ▶️ Trailer Player

- Trailer playback
- Play and pause controls
- Progress bar
- Playback controls
- Full-screen style presentation

### 🔍 Search

Search for movies and TV shows and browse results through a clean grid-based interface.

### 🛍️ Store

Browse featured movies and shows through a dedicated Store experience inspired by the Apple TV interface.

### 📚 Library

A dedicated Library section for accessing saved and available content.

## 🎨 Design

The interface is inspired by the visual style of Apple TV and focuses on:

- Cinematic dark UI
- Large movie and TV artwork
- Minimal interface elements
- Rounded cards
- Smooth navigation
- Content-focused layouts
- Clean typography
- Immersive media presentation

## 🎬 Movie & TV Data

This app uses the **TMDB API (The Movie Database)** to fetch movie and TV show information, including titles, posters, backdrops, ratings, descriptions, genres, seasons, episodes, and trailer information.

> This product uses the TMDB API but is not endorsed or certified by TMDB.
